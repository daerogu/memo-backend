# Memo Backend

클라우드컴퓨팅실습 개인 과제를 위해 제작한 FastAPI 기반 메모 애플리케이션 백엔드입니다.

Vercel에 배포된 Memo Frontend에서 요청을 받아 메모 관련 REST API를 제공합니다.

## 주요 기능

- 메모 목록 조회 API
- 메모 추가 API
- 메모 삭제 API
- CORS 설정
- Swagger UI를 통한 API 확인

## 사용 기술

- Python
- FastAPI
